In versions 2.0 and 3.0 of the sub-daily data, wet-bulb temperature observations from source 401 (column "source_id") were inadvertently reported as dew-point temperature. These values should not be used as dew-point temperatures. This will be corrected in the next scheduled release. See the [Known issues](https://cds.climate.copernicus.eu/datasets/insitu-observations-surface-land?tab=documentation) section in the Documentation tab for details.
