With the release of v202505, older versions (v201312 and v202212) will no longer be updated after 31/01/2026. This is expected to be adequate time given that the COMBINED and ACTIVE products for these versions are no longer regularly updated. Should a longer transition period be required users are requested to get in contact via the ECMWF support portal.
<br>Users should also note a change in the variable names, this impacts API requests - please see the 'Known Issues' in the Documentation tab for more information.
